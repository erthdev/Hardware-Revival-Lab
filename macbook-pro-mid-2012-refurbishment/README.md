# MacBook Pro Mid-2012 Revival

A personal refurbishment and upgrade project for a mid-2012 MacBook Pro.

This project began with an old MacBook Pro that had been sitting unused in a closet. After having it repaired, I gave it to my girlfriend as part of my monthsary gift.

What started as a simple repair eventually became a long-term project involving:

* Replacing the original 240 GB SSD with a 256 GB STORM M.2 SATA SSD
* Reinstalling macOS Catalina
* Attempting a RAM upgrade
* Investigating OpenCore Legacy Patcher
* Planning a 1 TB experimental boot drive
* Planning a 500 GB HDD upgrade by replacing the optical drive
* Exploring the possibility of turning the MacBook into a small home media server

The project is currently paused, but the MacBook is stable and fully usable with macOS Catalina.

For the complete refurbishment journey, troubleshooting process, and future plans, see the [full project log](logs.md).

---

## Current Configuration

* **Model:** MacBook Pro Mid-2012
* **Operating System:** macOS Catalina
* **RAM:** 8 GB DDR3
* **Storage:** 256 GB STORM M.2 SATA SSD
* **Future Storage:** 1 TB experimental drive and 500 GB HDD
* **Future Goal:** OpenCore Legacy Patcher and possible media server setup
